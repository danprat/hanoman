# Onboarding

Operator baru harus bisa memantau dalam < 10 menit.

1. Hubungkan GitHub (sumber commit-trigger).
2. Tambah project: **from-scratch** (brainstorm → objective → scaffold docs) atau **existing** (pilih direktori → reverse-engineer docs).
3. Set trigger (mis. commit → plan+execute).
4. Pantau di Overview & Runs.
